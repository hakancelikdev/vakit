§ 02 · Amanah

Datamu adalah amanah,
bukan barang dagangan.

Jangan biarkan ibadahmu terputus. Aplikasi salat lain pernah ketahuan menjual data lokasi. Vakit memilih jalan lain: koordinatmu tidak pernah sampai ke server kami. Tanpa akun. Tanpa pelacakan. Tanpa kompromi. Ini bukan fitur — ini prinsip.

01 / no account

Unduh. Buka. Salat.

Tanpa daftar, tanpa login, tanpa kata sandi yang bakal kamu lupakan. Vakit langsung bekerja begitu dipasang.

02 / on-device

Dihitung di ponselmu.

Jadwal salat dihitung langsung di perangkat berdasarkan lokasimu, dengan metode pilihanmu. Tidak ada yang dikirim ke server untuk ‘dicarikan’.

03 / no tracking

Lokasi tepatmu tidak ada pada kami.

Koordinatmu tidak pernah sampai ke server kami — kami hanya tahu negara, kota, dan kecamatanmu. Untuk alamat dan masjid terdekat, lokasi hanya dikirim ke Apple Maps.

04 / transparent

Kebijakan yang mudah dipahami.

Data penggunaan yang terikat pada kode samaran — tanpa nama, email, atau nomor telepon. Kebijakan privasi kami mencantumkan persis apa saja yang dikirim, dan cukup pendek untuk dibaca dalam semenit.
