آپ کا درست مقام ہمارے پاس نہیں۔

آپ کا درست مقام ہمارے سرورز کو نہیں بھیجا جاتا — ہم صرف ملک، شہر اور ضلع جانتے ہیں۔ آپ کے پتے اور قریبی مساجد کے لیے مقام صرف ایپل میپس کو جاتا ہے۔

سادہ زبان میں پالیسی۔

استعمال کا ڈیٹا ایک فرضی صارف کوڈ سے جڑا ہے — نہ نام، نہ ای میل، نہ فون نمبر۔ کیا کچھ بھیجا جاتا ہے، یہ ہماری رازداری کی پالیسی میں ایک ایک کر کے لکھا ہے، اور یہ اتنی مختصر ہے کہ ایک منٹ میں پڑھی جائے۔
